# 锅炉制造企业AI化给出可行性分析及实施方案

背景：锅炉制造国企，现有采购的erp系统,mes系统，WPS工作流系统,plm系统等，数据目前没有打通。需要对办公以及生产制造进行AI化改造，智慧办公+智慧工厂。


1. 需要对需求的可行性讨论，能力边界是什么
目前的部门有：
公司办（公司管理），人力资源，党群，财务，采购，安环（安全环保），质检（锅炉制造质检），总师办（体系，管理制度，标准管理及信息化），研究院，锅炉制造等部门
每个部门会有多个需求，会新增需求，有跨部门的需求。

例子：

研究院希望能实现自动化画图
质检希望能够实现AI质检焊缝
锅炉制造部门希望能够通过AI来实现自动推荐设备参数通过APP或者微信/钉钉给操作人员
等等。

2.需要对一些问题进行讨论
  数据安全及权限问题（包括敏感信息如何处理，比如财务信息只能固定的人才能查看）
  成本问题 （如需要私有化部署考虑到现有服务器架构不能简单的插卡支持AI硬件需求，需要新采购）
  还需要考虑到并发占用显存问题，建议并发预计为30个左右
  部署何种模型？
  扩展维护问题（若私有化部署购买AI服务器后，后期如何升级）
  如何与现有信息化系统进行对接，数据打通
对目前的需求来说，使用开源项目wanwu进行二次开发是否可行
为什么豆包等AI会东拉西扯，捏造不存在的资料？我们的方案如何解决这个问题
我们的解决方案目前能确保100%的准确性吗？幻觉问题
持续学习能力
- 如果用大模型 + 知识库，如何保证持续学习的能力
- Hermes 的持续学习能力是否可以引入
- Skill、工作流在业务中有什么作用

多需求且需要权限设置的场景，是否不适合训练一个大模型
最佳适配是否为 LLM + 知识库方案


平台统一性
- 是否可以通过一个平台（万悟）进行所有工作
- 还是需要其他解决方案

3.初步实现场景
文本纠错场景（优先落地）
- 场景：体系管理手册纠错/标准纠错/质保纠错/管理制度
（下面的信息是体系管理的，其他文本纠错类似）
- 手册基于体系管理文件（法规、国家标准等）人工编写，可能存在错误
- 纠错类型：引用错误、引用到错误的标准、瞎编的法规、引用到错误的数据、语法错误、逻辑错误
- 体系管理文件定期更新（法规、国家标准等）


 焊接质检（深度学习/CV）
- 识别质检图片，判断焊接是否达标
- 图片标注后训练模型，提高质检效率
- 涉及 YOLOv8 等视觉模型
